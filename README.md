### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication

### Frontend
- React.js (Vite)
- Axios
- React Router

## Features

### Admin
- Dashboard
- Add Users
- Add Stores
- View Users
- View Stores

### User
- Register/Login
- View Stores
- Submit Ratings (1-5)
- Update Ratings

### Store Owner
- View Ratings
- View Average Store Rating

## Setup

### Backend

```bash
npm install
npm run dev
```

### Frontend

```bash
npm install
npm run dev
```

### Database

Import SQL tables from database.sql
